# Streamlit E-Commerce Executive Intelligence App

## 1. Overview
The **Streamlit E-Commerce Executive Intelligence Application** is a decoupled, cloud-ready BI and analytical web application built on top of the **Olist Brazilian E-Commerce Ecosystem** (~100k orders, 2016–2018).

### Architectural Highlights
- **Zero-Database Dependency**: Reads directly from pre-aggregated, sanitized Parquet and CSV files in `data/exports/`. The app does not require a running MySQL instance, allowing free deployment on **Streamlit Community Cloud**, Render, or Hugging Face Spaces.
- **High-Performance Parquet Storage**: Uses columnar Parquet files generated by `src/analysis/generate_app_data.py` with compact datatypes (`uint8`/`uint16`/`float32`/`category`) and selective column loading (`usecols`), reducing memory footprint to ~380 MB (< 500 MB limit).
- **In-Memory Caching**: Utilizes `@st.cache_data` in `streamlit_app/data_loader.py` and `streamlit_app/kpi_metrics.py` to ensure instant sub-second page switches and re-filtering.
- **Pure-Python Analytical Engine**: Decoupled KPI calculation logic in `streamlit_app/kpi_metrics.py` dynamically computing baseline metrics from data tables without hardcoded numbers, fully verified with automated pytest tests.
- **Currency & Business Standards**: All monetary values are strictly in **Brazilian Reais (R$ / BRL)**. Revenue filters for completed transactions (`order_status = 'delivered'`) and excludes shipping freight. All financial margins are labelled *"assumed margin, not real data"*. RFM customer segmentation uses the data-accurate labels: `Top Value`, `Mid Value`, `Dormant`, and `Low Spend`.

## 3. Quickstart & Execution Guide

### Windows 11 (PowerShell)
```powershell
# 1. Navigate to the project root
cd "c:\Users\khana\Desktop\DAP 1"

# 2. Activate virtual environment
.\venv\Scripts\Activate.ps1

# 3. Ensure dependencies are installed
pip install -r requirements.txt

# 4. Launch the Streamlit application
streamlit run streamlit_app/app.py
```

The application will automatically open in your default browser at:
`http://localhost:8501`

### Pipeline Script Execution Order
When setting up or refreshing analytical exports from scratch:
```powershell
# 1. Clean raw Olist CSVs
python -m src.preprocessing.audit
python -m src.preprocessing.clean_data

# 2. Ingest and verify MySQL 8.0 database
python -m src.database.load_data
python -m src.database.verify_db

# 3. Generate statistical models and Power BI CSV star-schema exports
python -m src.analysis.run_eda
python -m src.analysis.export_powerbi_data

# 4. Generate high-performance Parquet tables & pre-aggregated cache for Streamlit
python -m src.analysis.generate_app_data

# 5. Launch web application
streamlit run streamlit_app/app.py
```

### Running KPI & Smoke Automated Tests
To verify that the standalone KPI calculation engine and all 14 dashboard view sections render with zero exceptions:
```powershell
pytest -v tests/test_streamlit_kpis.py tests/test_app_pages.py
```
Expected output:
- `total_revenue_brl`: **R$ 13,221,498.11**
- `total_delivered_orders`: **96,478**
- `repeat_customers_count`: **2,801**
